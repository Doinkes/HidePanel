# HidePanel

Мгновенно скрывающаяся панель задач для Windows 10/11.

Панель задач не висит на экране постоянно: она полностью скрыта и появляется **мгновенно**,
только когда курсор оказывается в самой нижней полосе экрана (по умолчанию — 2 пикселя).
Как только курсор уходит с панели — она исчезает так же мгновенно, без анимации и без задержек.

## Зачем

Штатное «автоматически скрывать панель задач» в Windows 11:

* выезжает с анимацией и задержкой ~100–300 мс;
* уезжает обратно через ~1–2 секунды после того, как курсор ушёл;
* может «моргнуть» при случайном касании нижнего края.

HidePanel убирает и задержки, и анимацию: показ/скрытие — это одно изменение видимости окна,
занимающее единицы миллисекунд. Заодно это полезно для OLED-мониторов: статичная панель
с иконками и часами не выводится на экран.

| | Штатное авто-скрытие | HidePanel |
|---|---|---|
| Появление | задержка + слайд-анимация | ~2 мс, без анимации |
| Исчезновение | задержка ~1 с + анимация | единицы мс, без анимации |
| Рабочая область | весь экран, панель поверх окон | место под панель зарезервировано |
| Показ поверх игр/видео | да | нет (опционально) |

## Как это работает

1. Программа запоминает текущее состояние штатного авто-скрытия и временно его отключает
   (`SHAppBarMessage(ABM_SETSTATE)`), чтобы оболочка не «боролась» с нами.
2. Панель задач (`Shell_TrayWnd` и `Shell_SecondaryTrayWnd`) прячется через `ShowWindow(SW_HIDE)`.
3. Отдельный поток каждые 5 мс читает позицию курсора. Курсор в нижней полосе или над панелью —
   панель показывается (`SetWindowPos` без активации), курсор ушёл — прячется.
4. При выходе исходное состояние авто-скрытия восстанавливается.

Отключение штатного авто-скрытия — вынужденная мера: Windows не даёт отключить анимацию
штатного механизма. Побочный эффект в том, что рабочая область уменьшается на высоту панели
(развёрнутые окна не заезжают под неё). Это же означает, что окна не «прыгают» при каждом
появлении панели.

## Установка

1. Скачайте `HidePanel-v1.0.0-win64.zip` из раздела **Releases** и распакуйте,
   например, в `C:\Tools\HidePanel`.
2. Запустите `HidePanel.exe`. Права администратора не нужны.
3. Выход — `Ctrl+Alt+Q` или `HidePanel.exe --quit`.

Автозапуск при входе в систему:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

Скрипт копирует программу в `%LOCALAPPDATA%\Programs\HidePanel`, добавляет запись в
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` и запускает её.

Удаление:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\uninstall.ps1
```

## Настройки

Файл `HidePanel.ini` рядом с `HidePanel.exe` (необязательный, см. `HidePanel.example.ini`):

```ini
[settings]
; толщина «горячей» полосы у края экрана, px
edge_px=2
; период опроса курсора, мс
poll_ms=5
; не показывать панель поверх полноэкранных игр/видео (1/0)
fullscreen_guard=1
; вернуть исходное авто-скрытие при выходе (1/0)
restore_on_exit=1
; писать лог в %LOCALAPPDATA%\HidePanel\HidePanel.log (1/0)
log=0
; горячая клавиша выхода
exit_hotkey=Ctrl+Alt+Q
```

Изменения применяются после перезапуска программы.

## Командная строка

```
HidePanel.exe                 запуск
HidePanel.exe --quit          остановить запущенный экземпляр
HidePanel.exe --restore       аварийно: показать панель и вернуть штатное авто-скрытие
HidePanel.exe --edge 3        толщина горячей полосы
HidePanel.exe --poll 10       период опроса, мс
HidePanel.exe --debug         подробный лог
HidePanel.exe --version
HidePanel.exe --help
```

Повторный запуск `HidePanel.exe` останавливает уже работающий экземпляр
(второй экземпляр не создаётся).

## Если что-то пошло не так

* Панель не появляется — нажмите `Ctrl+Alt+Q`, затем запустите `HidePanel.exe --restore`.
* Программа упала и панель осталась спрятанной — `HidePanel.exe --restore`
  (состояние хранится в `%LOCALAPPDATA%\HidePanel\state.ini`).
* Совсем ничего не помогает — `Ctrl+Shift+Esc` → «Проводник» → «Перезапустить».

## Ограничения и нюансы

* Windows 10/11, панель задач внизу (в Windows 11 её всё равно нельзя переставить).
* Несколько мониторов: обрабатываются все панели (если включено «показывать панель на всех
  дисплеях»), горячая зона — у края каждого монитора.
* Меню «Пуск» и другие всплывающие панели оболочки открываются на высоте рабочей области,
  то есть на 48 px выше нижнего края экрана.
* Если включить штатное авто-скрытие в «Параметрах» при работающей программе, она выключит
  его снова — иначе два механизма начнут конфликтовать.
* Полноэкранные приложения: панель не показывается поверх игр и полноэкранного видео
  (`fullscreen_guard=1`). Можно отключить.
* Программа не ставит иконку в область уведомлений (она ведь скрыта вместе с панелью),
  поэтому выход — только по горячей клавише или `--quit`.

## Сборка

Нужен MSVC (Visual Studio 2022 Build Tools с компонентом C++) либо MinGW-w64 (g++),
PowerShell 5.1+ и Windows SDK. Внешних зависимостей нет — только Win32 API.

```powershell
.\build.ps1                    # MSVC, если найден, иначе MinGW
.\build.ps1 -Compiler mingw    # принудительно MinGW
.\build.ps1 -Zip               # + dist\HidePanel-<версия>-win64.zip
.\build.ps1 -Clean
```

Результат: `dist\HidePanel.exe` (статическая линковка CRT, без зависимостей).

Иконка генерируется скриптом `tools/make-icon.ps1` (System.Drawing), готовый `assets/icon.ico`
уже лежит в репозитории.

## Тесты

```powershell
.\scripts\test.ps1
```

Скрипт запускает программу и проверяет: панель спрятана, штатное авто-скрытие выключено,
рабочая область не «прыгает», появление по нижней полосе (< 40 мс), удержание панели под
курсором, скрытие при уходе курсора (< 40 мс), 5 циклов подряд, восстановление настроек
после `--quit`. Требуется интерактивный рабочий стол; на время теста курсор перемещается.
