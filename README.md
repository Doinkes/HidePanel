# HidePanel

Мгновенно скрывающаяся панель задач для Windows 10/11.

Панель задач полностью скрыта и появляется **мгновенно**, только когда курсор оказывается
в самой нижней полосе экрана (по умолчанию — 2 пикселя). Как только курсор уходит с панели —
она исчезает так же мгновенно, без анимации и без задержек. При этом Windows считает экран
полностью свободным: развёрнутые окна занимают **весь монитор**, а панель рисуется поверх них.

## Зачем

Штатное «автоматически скрывать панель задач» в Windows 11:

* выезжает с анимацией и задержкой ~100–300 мс;
* уезжает обратно через ~1–2 секунды после того, как курсор ушёл;
* может «моргнуть» при случайном касании нижнего края.

HidePanel убирает и задержки, и анимацию: показ/скрытие — одно изменение региона окна,
занимающее единицы миллисекунд. Заодно это полезно для OLED-мониторов: статичная панель
с иконками и часами не выводится на экран.

| | Штатное авто-скрытие | HidePanel |
|---|---|---|
| Появление | задержка + слайд-анимация (~300 мс) | ~2 мс, без анимации |
| Исчезновение | задержка ~1 с + анимация | единицы мс, без анимации |
| Рабочая область | весь экран | весь экран |
| Развёрнутые окна | на весь экран, панель поверх | на весь экран, панель поверх |

## Как это работает

1. Программа запоминает текущее состояние штатного авто-скрытия и временно его отключает
   (`SHAppBarMessage(ABM_SETSTATE)`), чтобы оболочка не «боролась» с нами.
2. Рабочая область возвращается к полному размеру монитора: `SPI_SETWORKAREA` **без**
   `SPIF_SENDCHANGE`. Такой вызов оболочка не откатывает и не рассылает
   `WM_SETTINGCHANGE`, поэтому уже развёрнутые окна не дёргаются, а новые разворачиваются
   на весь экран. Раз в 0,5 с значение проверяется и при необходимости возвращается.
3. Панель «прячется» не через `SW_HIDE`, а через **пустой регион окна**
   (`SetWindowRgn`): окно остаётся видимым для оболочки (она не пересчитывает рабочую
   область и не пытается вернуть место под панель), но не рисуется и не перехватывает мышь.
   Показ — снятие региона. Обе операции мгновенные.
4. Отдельный поток каждые 5 мс читает позицию курсора. Курсор в нижней полосе — панель
   показывается, ушёл с панели — прячется.
5. При выходе исходное состояние авто-скрытия и рабочая область восстанавливаются.

## Установка

1. Скачайте `HidePanel-v1.1.0-win64.zip` из раздела **Releases** и распакуйте,
   например, в `C:\Tools\HidePanel`.
2. Запустите `HidePanel.exe`. Права администратора не нужны.
3. Выход — `Ctrl+Alt+Q`, пункт «Выход» в меню значка в трее или `HidePanel.exe --quit`.

Автозапуск при входе в систему:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

Скрипт копирует программу в `%LOCALAPPDATA%\Programs\HidePanel`, добавляет запись в
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` и запускает её.
Автозапуск также включается/выключается галочкой в меню значка.

Удаление:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\uninstall.ps1
```

## Значок в трее

При запуске программа добавляет значок в область уведомлений (при первом запуске Windows
может положить его в «скрытые» под стрелкой `^` — программа один раз просит показать его
на панели). Меню значка:

* **Запускать при входе в Windows** — включить/выключить автозапуск;
* **Настройки (HidePanel.ini)** — открыть файл настроек (создаётся при необходимости);
* **Выход** — остановить программу и вернуть панель задач.

Значок живёт внутри панели задач, поэтому виден только когда панель показана. Если панель
почему-то не появляется — работает горячая клавиша `Ctrl+Alt+Q`.

## Настройки

Файл `HidePanel.ini` рядом с `HidePanel.exe` (необязательный, см. `HidePanel.example.ini`):

```ini
[settings]
; толщина «горячей» полосы у нижнего края экрана, px
edge_px=2
; период опроса курсора, мс
poll_ms=5
; рабочая область = весь экран (панель поверх окон), 1/0
full_work_area=1
; не показывать панель поверх полноэкранных игр/видео (1/0)
fullscreen_guard=1
; вернуть исходное авто-скрытие при выходе (1/0)
restore_on_exit=1
; писать лог в %LOCALAPPDATA%\HidePanel\HidePanel.log (1/0)
log=0
; горячая клавиша выхода
exit_hotkey=Ctrl+Alt+Q
```

Изменения применяются после перезапуска программы.

## Командная строка

```
HidePanel.exe                 запуск
HidePanel.exe --quit          остановить запущенный экземпляр
HidePanel.exe --restore       аварийно: показать панель и вернуть штатное авто-скрытие
HidePanel.exe --edge 3        толщина горячей полосы
HidePanel.exe --poll 10       период опроса, мс
HidePanel.exe --debug         подробный лог
HidePanel.exe --version
HidePanel.exe --help
```

Повторный запуск `HidePanel.exe` останавливает уже работающий экземпляр
(второй экземпляр не создаётся).

## Если что-то пошло не так

* Панель не появляется — нажмите `Ctrl+Alt+Q`, затем запустите `HidePanel.exe --restore`.
* Программа упала, панель осталась спрятанной — `HidePanel.exe --restore`
  (состояние хранится в `%LOCALAPPDATA%\HidePanel\state.ini`).
* Совсем ничего не помогает — `Ctrl+Shift+Esc` → «Проводник» → «Перезапустить».

## Ограничения и нюансы

* Windows 10/11, панель задач внизу (в Windows 11 её всё равно нельзя переставить).
* Рабочая область расширяется через `SPI_SETWORKAREA`, а он относится к **основному**
  монитору. На вторичных мониторах с собственной панелью место под неё может остаться
  зарезервированным.
* Если оболочка снова зарезервирует место под панель (например, после смены темы или
  перезапуска explorer), программа вернёт полный экран в течение полусекунды.
* Если включить штатное авто-скрытие в «Параметрах» при работающей программе, она выключит
  его снова — иначе два механизма начнут конфликтовать.
* Полноэкранные приложения: панель не показывается поверх игр и полноэкранного видео
  (`fullscreen_guard=1`). Можно отключить.
* Значок в трее виден только вместе с панелью (он часть панели задач).

## Сборка

Нужен MSVC (Visual Studio 2022 Build Tools с компонентом C++) либо MinGW-w64 (g++),
PowerShell 5.1+ и Windows SDK. Внешних зависимостей нет — только Win32 API.

```powershell
.\build.ps1                    # MSVC, если найден, иначе MinGW
.\build.ps1 -Compiler mingw    # принудительно MinGW
.\build.ps1 -Zip               # + dist\HidePanel-<версия>-win64.zip
.\build.ps1 -Clean
```

Результат: `dist\HidePanel.exe` (статическая линковка CRT, без зависимостей).

Иконка генерируется скриптом `tools/make-icon.ps1` (System.Drawing), готовый `assets/icon.ico`
уже лежит в репозитории.

## Тесты

```powershell
.\scripts\test.ps1
```

Скрипт запускает программу и проверяет: панель спрятана, штатное авто-скрытие выключено,
рабочая область равна полному экрану, развёрнутое окно занимает весь монитор, появление
по нижней полосе (< 40 мс), удержание панели под курсором, скрытие при уходе курсора
(< 40 мс), сохранение полной рабочей области, 5 циклов подряд, восстановление настроек
после `--quit`. Требуется интерактивный рабочий стол; на время теста курсор перемещается.
