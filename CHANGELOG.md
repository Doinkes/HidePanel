# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-17

### Добавлено

* Мгновенное скрытие панели задач: `ShowWindow(SW_HIDE)` вместо слайд-анимации оболочки.
* Появление панели при попадании курсора в нижние 2 px экрана (~2 мс), скрытие при уходе
  курсора с панели (< 10 мс).
* Настройка толщины горячей полосы (`edge_px`), периода опроса (`poll_ms`) и горячей
  клавиши выхода (`exit_hotkey`).
* Отключение штатного авто-скрытия на время работы с восстановлением исходного состояния
  при выходе.
* Защита от падения: файл состояния в `%LOCALAPPDATA%\HidePanel\state.ini`,
  команда `--restore` для аварийного восстановления.
* `fullscreen_guard` — панель не показывается поверх полноэкранных игр и видео.
* Поддержка нескольких мониторов и вторичных панелей задач.
* Автоматическое восстановление после перезапуска `explorer.exe` (перечитывание окна панели).
* Один экземпляр программы; повторный запуск останавливает предыдущий.
* Сборка MSVC и MinGW-w64, CI на GitHub Actions, релизы по тегу `v*`.
