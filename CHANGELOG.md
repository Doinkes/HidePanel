# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [1.2.0] — 2026-11-17

### Добавлено

* Окно настроек (пункт «Настройки…» в меню значка) вместо открытия ini в блокноте:
  все параметры с пояснениями, кнопки «Сохранить», «Отмена», «По умолчанию».
* Выбор языка интерфейса — русский / английский. Переключается прямо в окне настроек,
  применяется и к меню значка; по умолчанию берётся язык системы (`language=auto`).
* Изменения из окна применяются сразу: толщина полосы, период опроса, режим полного экрана,
  fullscreen-guard, горячая клавиша (перерегистрируется на лету).

### Изменено

* Настройка `language` в `HidePanel.ini` (`ru`, `en`, `auto`).
* Заголовок окна настроек и подсказка значка переводимые.

## [1.1.0] — 2026-11-17

### Изменено

* Панель больше не занимает место на экране: рабочая область возвращается к полному
  размеру монитора (`SPI_SETWORKAREA` без broadcast), развёрнутые окна занимают весь экран,
  а панель рисуется поверх них.
* Скрытие панели переведено с `ShowWindow(SW_HIDE)` на пустой регион окна (`SetWindowRgn`):
  оболочка больше не пересчитывает рабочую область и не «воюет» с программой.

### Добавлено

* Значок в области уведомлений с меню: выход, автозапуск, открыть настройки.
  При первом запуске значок автоматически выносится из «скрытых» на панель.
* Настройка `full_work_area` (по умолчанию 1).
* Проверка полной рабочей области и развёрнутого окна в `scripts/test.ps1`.

### Исправлено

* Кириллица в интерфейсе при сборке MSVC (`/utf-8`).
* Лог больше не забивается повторяющимися строками про зоны панели.

## [1.0.0] — 2026-11-17

### Добавлено

* Мгновенное скрытие панели задач: `ShowWindow(SW_HIDE)` вместо слайд-анимации оболочки.
* Появление панели при попадании курсора в нижние 2 px экрана (~2 мс), скрытие при уходе
  курсора с панели (< 10 мс).
* Настройка толщины горячей полосы (`edge_px`), периода опроса (`poll_ms`) и горячей
  клавиши выхода (`exit_hotkey`).
* Отключение штатного авто-скрытия на время работы с восстановлением исходного состояния
  при выходе.
* Защита от падения: файл состояния в `%LOCALAPPDATA%\HidePanel\state.ini`,
  команда `--restore` для аварийного восстановления.
* `fullscreen_guard` — панель не показывается поверх полноэкранных игр и видео.
* Поддержка нескольких мониторов и вторичных панелей задач.
* Автоматическое восстановление после перезапуска `explorer.exe` (перечитывание окна панели).
* Один экземпляр программы; повторный запуск останавливает предыдущий.
* Сборка MSVC и MinGW-w64, CI на GitHub Actions, релизы по тегу `v*`.
